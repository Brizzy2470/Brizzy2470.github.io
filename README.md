# Brandon-Portfolio

This is a fork of the [AtumCor/Persona-Portfolio](https://github.com/AtumCor/Persona-Portfolio)

To run the project locally, use the following commands:

Pre-requisites
Have nvm and node installed

Install dependencies
```bash
npm install
```

To start the server locally
```bash
npm run dev
```


.css is the styling
.tsx is the actual website content
